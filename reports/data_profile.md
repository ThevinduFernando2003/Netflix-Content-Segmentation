## Contract versus the file on disk

The brief describes the public Netflix titles dump (`cast`, `description`, about 8,791 rows, dates like `September 25, 2021`). **This file wins where they disagree.**

- Rows: **8790**. Columns: `['show_id', 'type', 'title', 'director', 'country', 'date_added', 'release_year', 'rating', 'duration', 'listed_in', 'cast', 'description']`.
- `cast` and `description` are **absent**. The loader adds empty strings. The text block is therefore the title only.
- Missing director and country are the literal token `not given`, not nulls.
- `date_added` is `M/D/YYYY` (and was mixed with Excel datetimes before the CSV export).
- Rating values matching `^\d+\s*min$`: **0**. The cleaner still handles that defect.
